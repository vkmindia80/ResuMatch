## What Happens Behind the Scenes?

### Step 1: Initial Generation
- AI creates professional summary with 10-12 keywords
- Optimizes experience bullets with quantification
- Prioritizes skills to match job requirements

### Step 2: ATS Scoring
- Analyzes keyword match (30 points)
- Checks format compatibility (20 points)
- Evaluates action verbs (20 points)
- Reviews quantification (15 points)
- Assesses impact statements (15 points)

### Step 3: Iterative Optimization (Up to 5 Rounds)

**Iteration 1**: Fix critical keyword gaps
- Adds missing must-have skills
- Improves summary keyword density

**Iteration 2**: Enhance action verbs & quantification
- Replaces weak verbs with power verbs
- Adds metrics to bullets

**Iteration 3**: Boost impact statements
- Emphasizes business results
- Strengthens value proposition

**Iteration 4-5**: Final polish (if needed)
- Fine-tunes keyword placement
- Perfects quantification

**Target**: Stop when score reaches **96%+** or after 5 iterations

## Tips for Best Results

### ✅ Do This

1. **Complete Your Profile**
   - Fill all sections (experience, skills, education)
   - Add quantifiable achievements
   - List all relevant technical skills

2. **Provide Full Job Description**
   - Copy entire job posting
   - Include requirements section
   - Don't skip technical details

3. **Use Exact Job Terminology**
   - If job says "React.js", profile should have "React" or "React.js"
   - Match acronyms (AWS vs Amazon Web Services)
   - Use industry-standard terms

4. **Trust the System**
   - Let it run all iterations
   - Don't interrupt optimization
   - Review final result before customizing

### ❌ Avoid This

1. **Incomplete Profiles**
   - Missing work experience
   - Vague job responsibilities
   - No technical skills listed

2. **Generic Job Descriptions**
   - Just job title without details
   - Missing requirements section
   - No technical skills listed

3. **Over-customization**
   - Making resume too specific to one role
   - Removing important experiences
   - Changing optimized content unnecessarily

## Troubleshooting

### "My score is only 90%, not 96%+"

**Possible causes:**
1. **Profile incomplete** → Fill all sections
2. **Generic job description** → Provide detailed requirements
3. **Skills mismatch** → Add relevant skills to profile
4. **No quantification** → Add metrics to achievements

**Solution**: Update profile, re-generate with detailed job description

---

### "Keywords score is low (< 26/30)"

**Possible causes:**
1. Job description skills not in profile
2. Using different terminology (JS vs JavaScript)
3. Missing critical technical skills

**Solution**: 
- Add missing skills to profile
- Use exact terms from job posting
- List all relevant technologies

---

### "Action verbs score is low"

**Possible causes:**
1. Experience bullets don't start with action verbs
2. Weak verbs (worked, helped, assisted)

**Solution**:
- Profile should have results-oriented language
- Use: Led, Architected, Delivered, Increased, Reduced
- System will enhance, but better input = better output

---

### "Quantification score is low"

**Possible causes:**
1. No metrics in experience bullets
2. Vague achievements without numbers

**Solution**:
- Add percentages, dollar amounts, time saved
- Include team sizes, user counts, scale
- Example: "Managed project" → "Led team of 8 engineers"
